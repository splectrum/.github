# SPLectrum

SPLectrum began as a software engineering idea, a DSL engine for language and
meaning, and has grown into a philosophy with language as the medium:
[splectrum.world](https://splectrum.world). Its engineering is an effort to
build a technological reality in the same image, on three pillars: **HAICC**,
human-AI creative collaboration, and now the platform that runs;
**Mycelium**, the data repository; and **SPLectrum** itself, the language
fabric, a DSL engine still to be built. They run on peer-to-peer swarms, and
are built with AI autonomy in mind: from a need to running software.

This organisation is where the work is planned and done: the roadmap, the
development environments, and the site. The language modules will live here
once the language layer is built.

## The seven organisations

SPLectrum's engineering is spread over seven GitHub organisations:

- **[splectrum](https://github.com/splectrum)** (this one): where SPLectrum, the
  philosophy project, lives, and where its engineering is planned.
- **[bare-for-pear](https://github.com/bare-for-pear)**: outside code
  changed to run on Bare. It rests until the platform needs it.
- **[pear-full-square](https://github.com/pear-full-square)**: the engines,
  all of the platform's code, one module a repository.
- **[HAICCing](https://github.com/haiccing)**: the packages made from those
  modules, and the `haicc` command: what you can run. Start here.
- **[myctral](https://github.com/myctral)**: mycelium's data
  repositories: state.
- **[myctrans](https://github.com/myctrans)**: data transformation:
  process.
- **[SPLectral](https://github.com/splectral)**: interaction, first of
  all the UI.
