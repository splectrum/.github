# SPLectrum

A framework at the intersection of philosophy of language, systems theory, and software engineering. Three fabrics: Mycelium (data), SPLectrum (language), HAICC (cognition).

Data repositories with embedded functionality — git repos that carry their own code, schemas, and references as colocated metadata. The solution layer, built on infrastructure from [bare-for-pear](https://github.com/bare-for-pear) and [pear-full-square](https://github.com/pear-full-square).

**[splectrum.world](https://splectrum.world)** — philosophy, engineering, and the seed principles.
